# ⏱️ JavaScript Stopwatch

A simple and interactive stopwatch built using HTML, CSS, and JavaScript.

## ✨ Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record lap times
- Responsive design
- Neon Pink theme

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 What I Learned

- JavaScript functions
- DOM manipulation
- Event listeners
- setInterval() and clearInterval()
- Creating dynamic HTML elements
